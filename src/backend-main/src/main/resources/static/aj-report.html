打不开时先检查这些地方

  • AJ-Report 是否已经启动，默认访问地址通常是 http://127.0.0.1:9095/。
  • application.yaml 中的 integration.aj-report.base-url 和 entry-path 是否填写正确。
  • AJ-Report 的数据库 SQL 是否已经导入，conf/bootstrap.yml 中数据库账号密码是否正确。
  • 如果内嵌区域空白，通常是 AJ-Report 不允许被 iframe 加载，这时请使用“直接打开 AJ-Report”。
